## 4. 検出した不具合

`docs/defects.md`参照。**計13件**。公開前の3種レビュー(Opus再確認・別コンテキストOpus・Codex)により、実装完了後に7件の**公開ブロッカー級**を含む追加8件が発見され、全て修正・回帰テスト化済み。

| ID | 概要 | 重大度 | 検出フェーズ |
|---|---|---|---|
| DEF-001 | `int()`/`Decimal()`が全角数字を暗黙に受理 | 中 | 実装前調査 |
| DEF-002 | 正規表現`\d`がUnicode数字にマッチしunit_priceの全角チェック漏れ | 中 | 実装中(pytest) |
| DEF-003 | mutmutがネイティブWindows非対応 | 低(環境制約) | ツール実行時 |
| DEF-004 | ブランチ`master`とCIトリガー`main`の不一致でCI不起動 | 高 | 公開前レビュー |
| DEF-005 | トレーサビリティ表に実在しないテスト関数名 | 中 | 公開前レビュー |
| DEF-006 | 列数不足のCSV行でクラッシュ | 高 | 3レビュー全員 |
| DEF-007 | エラーCSVのパス列がサニタイズから漏れ | 中 | 3レビュー全員 |
| DEF-008 | 書込失敗時にexit 2にならない | 高 | 別コンテキスト |
| DEF-009 | 入力=出力でデータ破壊(exit 0で沈黙) | **最高** | Codex |
| DEF-010 | Decimal28桁超で金額が黙って誤計算 | 高 | Codex |
| DEF-011 | Slack Webhook URL(秘密情報)のログ漏洩 | 高 | Codex |
| DEF-012 | 読込時OSErrorで全体停止 | 中 | Codex |
| DEF-013 | 関数は単体テスト済みだが配線が未検証(手動ミューテーション12件中8件生存) | 高 | 別コンテキスト |

> **教訓**: DEF-004/005/006/007/013はいずれも**自動テスト単体では検知できない種類の欠陥**(CI設定の不整合・ドキュメントと実装の乖離・配線の未検証)であり、カバレッジ100%でも防げなかった。特にDEF-009(データ破壊)・DEF-010(金額誤計算)・DEF-011(秘密漏洩)は実装者自身(Sonnet実装+Opus再確認)が見落とし、外部の別コンテキストレビュー・Codexが発見した。**「多角レビューは自動テスト・単一レビューの代替にならない」**ことを、この成果物自体が実例として証明している。

## 6. リリース可否判断

**条件付きGo**（無条件のGoではない）。

**達成済み**: 計画した全観点(同値分割・境界値・デシジョンテーブル・プロパティベース・ゴールデン・堅牢性・性能・セキュリティ・配線検証)を実施。行/分岐カバレッジ100%、lint/型チェック全通過、ローカルでPython 3.11・3.14の両方で全通過。公開前の3種レビューで発見した公開ブロッカー級7件を含む不具合13件は全て修正・回帰テスト化済み。手動ミューテーションを体系的に2回(Opus再確認時8件・FIX-08配線検証8件)実施し全て検知、各個別修正でもコミット前に赤→緑確認を実施済み。

**公開完了とみなすための残条件**（これを満たすまで「品質保証済み」と主張しない）:

1. **CI(`ci.yml` / `security.yml` / `mutation.yml`)が実際に緑になることを目視確認する** — 設定は書いたが一度も動かしていない。DEF-004(ブランチ名不一致でCIが起動しない)が実際に起きた通り、「書いた」と「動く」は別物。
2. **`mutation.yml`を実行し、ミューテーションスコアの実測値を取得してREADMEに記載する** — 設計時の完了基準であり、現状は手動サンプル20/20で代替している状態。
3. **GitHub Pagesのカバレッジレポート公開が機能することを確認する**（リポジトリ設定で Pages の Source を "GitHub Actions" に設定する必要がある）。

上記1〜3が未了の状態でも、コード品質・テスト設計・ドキュメントは公開に足る水準にある。ただし**READMEのバッジは公開直後は「一度も成功していないCI」を指す**ため、CIを緑にするまではバッジが赤/不明表示になる点を認識しておく。

> この「条件付きGo」という結論自体が、テスト完了報告書の役割そのもの——「どこまでやったか」ではなく**「何が残っているかを言えること」**——の実践例である。そして本レポートの前バージョン(2026-07-26時点)が「不具合5件・条件付きGo」としていたのに対し、その直後の3種レビューで公開ブロッカー級7件を含む追加8件が見つかったという事実自体が、**「条件付きGo」の"条件"を軽視してはならない**ことの実例である。
